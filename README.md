# 🍭 Operação Doce Proibido

Um jogo para aprender SQL de forma divertida, inspirado em *O Incrível Mundo de Gumball*.

A Mamãe Nicole proibiu doces no mercado. Ajude Gumball e Darwin a usar SQL para encontrar os doces, fugir das câmeras de segurança e descobrir quem está enchendo o carrinho. (Spoiler: sobra pro Ricardo. 😅)

## 🎮 Jogue agora
👉 https://esccluc-1810.github.io/operacao-doce-proibido/

## 📚 O que você vai praticar
São 11 fases, do básico ao intermediário:

- `SELECT`, `FROM` e `WHERE`
- `AND`, `ORDER BY` e `LIMIT`
- `DISTINCT` e `SUM`
- `JOIN` e `GROUP BY`
- `DELETE` (e por que nunca esquecer o `WHERE`!)

Cada fase tem uma missão, uma explicação curta e uma dica com as peças do código embaralhadas. Você descobre a ordem certa e escreve a consulta.
